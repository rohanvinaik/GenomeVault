## Maintaining Chain of Evidence

### Best Practices
1. **Never delete** original documents (even if outdated)
2. **Archive** all versions (shows evolution of thinking)
3. **Date everything** (handwritten dates on printouts count!)
4. **External timestamps** (email to yourself, GitHub commits)
5. **Third-party witnesses** (collaborators, advisors)

### What NOT To Do
- ❌ Don't backdate documents (looks suspicious)
- ❌ Don't delete "embarrassing" early work (shows authenticity)
- ❌ Don't claim earlier dates without evidence
- ❌ Don't modify timestamps on files
